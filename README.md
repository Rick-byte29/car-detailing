# APEX Auto Studio

A cinematic car detailing and repair service website demo.

## Run locally

Serve this directory with any static web server. For example, run `python -m http.server 8000` and open `http://localhost:8000`.

## Notes

- This is a static website. Three.js, the compressed 3D vehicle model, images, and decoder files are included under `vendor/` and `assets/`.
- Catalogue prices and the brand are illustrative demo content.
- Enquiry forms prepare a copyable message only. They do not create an appointment or send customer details.
- The included vehicle and photographs are credited on the site's Asset credits panel.
